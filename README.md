# routecase

Route HTML/Markdown case fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/routecase/

## Install / run

```bash
git clone https://github.com/theworker02/routecase.git
cd routecase
node src/cli.js
node --test
```
